# Автозаполнение Excel-файла с товарами

Этот проект содержит скрипт и простое веб-приложение для автоматического заполнения недостающих данных в листе **"Товары"** Excel-файла. Данные берутся из SQLite‑базы и, при необходимости, генерируется описание товара с помощью OpenAI API.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Использование CLI

```bash
python fill_products.py --input input.xlsx --db products.db --output result.xlsx --api-key YOUR_OPENAI_KEY
```

Все параметры обязательны, ключ API можно передать через переменную окружения `OPENAI_API_KEY`.

## Запуск веб-интерфейса

Для запуска Streamlit-приложения выполните:

```bash
streamlit run app.py
```

В приложении можно загрузить Excel-файл и скачать обработанный результат.
