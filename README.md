# Telegram Assistant "Стильные решения"

Минимальный пример Telegram-бота для сотрудников компании. Бот выполняет расчёт стоимости изделий, генерирует описания и изображения, отвечает инструкциями и информацией о доставке. Новые пользователи автоматически добавляются в список разрешённых.

## Запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте переменные окружения `TELEGRAM_BOT_TOKEN` и `OPENAI_API_KEY`.
3. Запустите бота:
   ```bash
   python main.py
   ```
